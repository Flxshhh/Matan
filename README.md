# Конспекты

Сайт-учебник: **предметы → лекции → темы**, с поиском по тексту всех конспектов.

- Каждая лекция — это PDF в `content/<предмет>/`.
- Темы внутри лекции берутся автоматически из закладок (оглавления) PDF:
  закладка верхнего уровня = отдельная тема, вложенные = подтемы (кнопки-переходы внутри темы).
- Поиск идёт по тексту страниц, результат — конкретная тема и страница; найденное подсвечивается прямо на странице.
- Масштаб страниц (кнопки − / + , клавиши `+` `-` `0`, Ctrl + колесо или щипок на тачпаде): страницы перерисовываются под реальный размер,
  поэтому при увеличении текст и формулы остаются чёткими. На телефоне то же самое при зуме пальцами.
- Лекцию можно читать целиком (`#/<предмет>/<лекция>/all`), а не только по темам.
- Отметки «изучено» хранятся в браузере.

## Как добавить лекцию

1. Положи PDF в папку предмета с номером в имени: `content/matan/14.pdf`.
2. Пересобери индекс: `python3 tools/build.py`
3. Закоммить и запушь — GitHub Actions сам пересоберёт и опубликует сайт.

## Как добавить предмет

1. Создай папку, например `content/algebra/`.
2. Добавь `content/algebra/meta.json`:
   ```json
   {
     "title": "Линейная алгебра",
     "short": "Алгебра",
     "description": "Матрицы, определители, линейные пространства.",
     "order": 2
   }
   ```
3. Положи туда PDF-ки `01.pdf`, `02.pdf`, … и запусти `python3 tools/build.py`.

### Настройки в `meta.json`

| Поле | Что делает |
|---|---|
| `title`, `short`, `description` | Названия предмета (полное, короткое для меню) и описание |
| `order` | Порядок предмета на главной |
| `color` | Цвет предмета: вкладка, кнопки, полоска у заголовка (по умолчанию синий `#4a7cf0`) |
| `content_start` | С какой страницы начинается текст (по умолчанию 3: 1 — обложка, 2 — оглавление) |
| `title_fixes` | Исправления заголовков тем, у которых в закладках PDF потерялись формулы: `{"как в PDF": "как надо"}` |
| `lectures` | Настройки отдельных лекций: `{"13": {"title": "…", "title_fixes": {…}, "content_start": 3}}` |

Если у PDF нет закладок, лекция станет одной темой. Текст до первой закладки становится темой «Введение».

## Локальный запуск

```bash
pip install -r tools/requirements.txt   # + poppler-utils (pdftotext)
python3 tools/build.py
python3 -m http.server 8000             # открыть http://localhost:8000
```

Открывать `index.html` двойным кликом нельзя — браузер не даст загрузить JSON и PDF с диска.

## Публикация

GitHub → Settings → Pages → Source: **GitHub Actions**. Дальше каждый пуш в `master` обновляет сайт.

## Устройство

```
index.html            — оболочка страницы
assets/app.js         — навигация, просмотр PDF (PDF.js), поиск
assets/style.css      — стили (светлая/тёмная тема, мобильная версия)
tools/build.py        — PDF → data/catalog.json + data/search.json
content/<предмет>/    — PDF и meta.json
data/                 — сгенерированные файлы (не править руками)
```
